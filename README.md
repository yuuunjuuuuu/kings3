# KCDA 웹사이트 프로토타입

한국커리어디자인협회(KCDA) 공식 웹사이트 프로토타입입니다. 순수 HTML/CSS/JS 단일 파일(`index.html`)로 제작되었으며, 별도의 빌드 과정이나 서버가 필요 없습니다.

## 배포 (Vercel)

1. 이 저장소를 GitHub에 올립니다.
2. [vercel.com](https://vercel.com)에서 GitHub 계정으로 로그인 후 "Import Project"로 이 저장소를 선택합니다.
3. Framework Preset은 "Other"(정적 사이트)로 두고 별도 빌드 명령 없이 배포하면 됩니다.
4. 이후 `main` 브랜치에 push할 때마다 자동으로 재배포됩니다.

## 참고 사항

- 로그인/회원가입은 브라우저 `localStorage` 기반 데모 기능입니다. 실제 회원 데이터베이스와 연동되어 있지 않으며, 방문자별 브라우저에만 저장됩니다.
- 페이지 내 논문 자료 중 "협회 자체 연구자료"로 표기된 항목은 협회 내부 자료이며, 외부 학술 데이터베이스에 등재된 논문이 아닙니다. 별도로 "외부 학술논문"으로 표기된 항목만 실제 등재 논문입니다.
- 이미지가 base64로 파일에 포함되어 있어 `index.html` 용량이 약 3MB입니다.
